About the Project :
1. The College Admission Guide is a Streamlit web application that helps students find suitable colleges and scholarships after 12th grade.
2. It uses two datasets: colleges.csv and scholarships.csv to generate personalized recommendations.
3. Users can filter results based on 12th marks, preferred city, and annual fee budget.
4. The app displays matching colleges along with relevant scholarship options to support financial planning.
5. It simplifies the admission process by providing all important information in one place.
   
Tech Stack :
Python
Streamlit
Pandas (for data handling)
CSV datasets (colleges & scholarships data)
